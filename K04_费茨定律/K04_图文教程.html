费茨定律

从数学公式到触控热区设计
人机交互运动定律 理论延伸 约2分钟

什么是费茨定律

1954年，心理学家 Paul Fitts 提出了一个关于人类指向运动的数学模型。他发现：人将指针从起点移动到目标所需的时间，取决于起点到目标的距离和目标的大小。

这个定律被后人称为"费茨定律"（Fitts's Law），是人机交互领域最重要的运动定律之一，也是触控界面设计、按钮尺寸规范、导航布局策略的理论基石。

费茨定律公式

MT = a + b · log₂(2D / W)
MT
运动时间
D — Distance
起点到目标的距离
W — Width
目标宽度
a, b
经验常数
设计师视角：a和b是与设备相关的经验常数，设计师无法控制。我们能控制的是D（距离）和W（宽度）两个变量。
距离越远→MT越大
目标越小→MT越大
即：距离越远、目标越小，操作越慢

三种情况对比

🟢
近 + 大
MT 最小
快速命中
🟡
远 + 大
MT 较大
稍慢
🔴
远 + 小
MT 最大
很慢

设计师的策略：缩短D（操作距离）+ 增大W（目标尺寸），让用户操作更快更准。

应用一：触控热区规范

平台最小触控区域说明
Apple iOS HIG44 × 44 ptApple 人机交互指南的下限要求
Material Design48 × 48 dpGoogle Material 规范的下限要求
设计建议56 dp 以上主操作按钮推荐尺寸

Apple和Google均基于费茨定律计算出"大多数用户在合理时间内能命中的最小目标尺寸"。

应用二：拇指热区

单手持握手机时，拇指的自然活动范围呈现三个区域：

困难区（顶部1/3）
伸展区（中间1/3）
自然区（底部1/3）
底部Tab栏 ← 在自然区

自然区：拇指自然弯曲即可到达 → 放高频操作

伸展区：拇指需要伸展 → 放中频操作

困难区：需要调整握姿 → 避免放关键操作

应用三：边缘效应

屏幕边缘的目标等效于"无限大"（W→∞），因为光标/手指无法超出屏幕边界，MT趋近最小值。

屏幕中间目标
需要精准对准
W有限 → MT较大
屏幕边缘目标
推到底就行
W→∞ → MT最小

经典应用：macOS Dock栏（底部边缘）、Windows任务栏（底部边缘）、iOS控制中心（顶部下拉）

正反面案例

✗ 反面案例

弹窗关闭按钮仅 20×20px
紧邻其他按钮间距 4px

→ 目标小 + 间距近
→ 用户误触率高
→ W被"侵蚀"，MT增加

✓ 正面案例

关闭按钮 44×44px
与相邻按钮间距 16px

→ 目标大 + 间距足
→ 精准操作
→ W充足，MT最小

相邻按钮间距不足时，有效目标宽度W被"侵蚀"，MT增加且误触概率上升。

设计自查清单

✓
触控区域 ≥ 44pt（iOS）/ 48dp（Android）在Figma中测量元素实际可点击区域
✓
高频操作位于屏幕底部1/3（拇指自然区）检查主要CTA按钮的Y坐标
✓
主操作按钮尺寸 > 次操作按钮对比两种按钮的宽高
✓
相邻按钮间距 ≥ 8px测量按钮间空白距离
✓
高频功能靠近屏幕边缘检查导航栏/工具栏位置

三条设计原则

1
缩短操作距离（D↓）
高频操作放在拇指自然区
2
放大触控目标（W↑）
触控热区 ≥ 44pt，主按钮 56dp+
3
利用屏幕边缘（W→∞）
导航栏、工具栏靠边放置
