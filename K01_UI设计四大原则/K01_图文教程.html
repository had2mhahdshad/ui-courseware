UI 设计四大基本原则

好设计的底层逻辑
设计基础理论 入门必修 约2分钟

为什么需要设计原则

你有没有过这种感觉——有的 App 用起来特别顺，有的却处处碰壁？这不是运气问题，而是设计有章可循。

UI 设计四大基本原则是判断一个设计"好不好用"的基本标尺。无论是网页、App 还是软件界面，好的设计几乎都遵循这四条原则。

四大原则概览

🎯

一致性原则

CONSISTENCY

视觉、操作、术语三统一，降低用户学习成本

🧠

易用性原则

USABILITY

操作直觉化，用户"凭感觉"就能用

📐

层级性原则

HIERARCHY

信息主次分明，引导用户视线流动

📱

规范性原则

STANDARDIZATION

遵循平台规范，利用已有心智模型

原则一：一致性

一致性是四大原则的基础。一个不一致的设计，会让用户每到一个新页面都要"重新学习"，认知负担大大增加。

核心含义：相同功能的元素，在不同页面看起来、用起来、说起来都应该一样。

一致性的三个维度

🎨
视觉统一
颜色、字体、图标风格、圆角大小、间距规范保持一致
👆
操作统一
相同功能的交互方式一致，如返回按钮始终在同一位置
📝
术语统一
同一概念在不同场景用相同表述，不混用同义词

✗ 反面案例

首页返回按钮在左边，详情页返回按钮在右边
按钮颜色每个页面都不一样
"确定"和"确认"混用

✓ 正面案例

所有页面返回按钮都在左上角
主按钮颜色全站统一
统一用"确定"不用"确认"

原则二：易用性

易用性是设计的目标。好的设计应该让用户"不用想就会用"——操作符合直觉，出错了也能轻松补救。

维度说明设计方法
可识别性用户能快速理解元素功能使用通用图标 + 文字标签
可预测性操作结果符合用户预期遵循常见交互模式
容错性出错后能轻松挽回提供撤销、确认、错误提示
衡量标准：用户第一次使用时，能否在 3 秒内找到主要功能？操作出错时，能否快速撤销？如果答案是肯定的，易用性就过关了。

原则三：层级性

层级性是信息传达的手段。用户的注意力是有限的——通过视觉权重的差异化，告诉用户"先看什么，后看什么"。

产品介绍
这是一个很棒的产品
产品功能非常强大，可以满足你的各种需求。快来体验吧！
✗ 没有层级 — 信息一片平
产品介绍
这是一个很棒的产品
产品功能非常强大，可以满足你的各种需求。
立即体验
✓ 层级清晰 — 视线有引导

建立层级的四要素

1
大小差异重要信息字号更大，标题 > 正文 > 辅助文字
2
颜色对比关键元素用更突出的颜色（品牌色/强调色）
3
间距/留白重要内容周围留白更多，视觉上更"透气"
4
位置优势黄金位置（顶部/左上/底部中央）放最重要的信息

原则四：规范性

规范性是设计的保障。每个平台都有自己的设计语言和用户习惯。遵循规范，就是利用用户已经建立的心智模型。

🍎
iOS
HIG
Human Interface Guidelines
简洁·优雅·重内容
🤖
Android
Material Design
纸片·投影·动效
Google 设计语言
🌐
Web
WCAG / WAI-ARIA
无障碍访问
通用可用性标准
为什么要遵循规范？因为用户不是第一次用手机/电脑。他们在用你的产品之前，已经用了无数个其他 App。遵循平台规范，就是利用用户已有的经验——你的产品"看起来就会用"。

四原则的关系

四大原则不是孤立的，而是相互支撑的整体：

易用性（目标）
规范性（保障）
层级性（手段）
一致性（基础）
一致性 = 基础 层级性 = 手段 规范性 = 保障 易用性 = 目标

一致性是最底层的基础——没有一致性，其他原则都无从谈起。层级性是信息传达的手段，规范性是跨平台的保障，最终的目标都是为了易用性。

设计自查清单

做完设计后，用这四条原则快速自查一遍：

✓
一致性检查按钮/颜色/字体/术语是否全站统一？
✓
易用性检查新用户能在3秒内找到主要功能吗？
✓
层级性检查信息有主次吗？用户知道先看什么吗？
✓
规范性检查是否符合所在平台的设计规范？
