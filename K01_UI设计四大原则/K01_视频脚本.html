制作概述

视频类型知识讲解型（口播 + 图解 + 案例对比 + 口诀总结）

标注"规范性 · 利用心智模型"
一致性是基础——按钮位置、颜色、术语统一，用户不用每次重新学习。层级性是手段——通过大小、颜色、间距的差异，告诉用户先看什么后看什么，信息越清晰越好找。易用性是目标——好设计就是让用户不用想。规范性是保障——iOS 有人机交互指南，Android 有 Material Design，跟着规范走，用户上手最快。
一致性 = 基础（三统一）
层级性 = 手段（主次分明）
易用性 = 目标（直觉操作）
规范性 = 保障（平台规范）

制作注意事项

1. 四原则配色方案：四个原则分别用不同的主题色区分——一致性用红色（#EF4444）、易用性用绿色（#10B981）、层级性用蓝色（#3B82F6）、规范性用紫色（#8B5CF6）。整体画面主色为青蓝色（#06B6D4）。颜色区分要明显但不刺眼，保持整体协调。

2. 口诀记忆点设计：四句口诀是视频的核心记忆点，需要用大字号、强对比呈现。建议每句口诀占满屏幕 1-2 秒，配合"飞入"动效和清脆的提示音，加深观众印象。口诀文字用 64px 以上大字，居中对齐。

3. 正反案例对比节奏：镜头 3 的正反案例是视频的"Aha Moment"——先展示反面案例的"糟糕体验"，再展示正面案例的"顺畅体验"，对比越强烈越好。反面案例可以用红色边框 + 错误标识，正面案例用绿色边框 + 正确标识。

4. 金字塔关系图制作要点：四原则的"基础-手段-保障-目标"关系是本知识点的核心认知框架。金字塔从下往上依次是：一致性（最宽，基础）→ 层级性（手段）→ 规范性（保障）→ 易用性（最尖，目标）。每层之间用箭头标注"支撑"关系。

5. 录音要求：旁白采用专业配音或 AI 语音（推荐使用标准普通话女声，语速适中偏快，每分钟约 210 字），情绪平稳但有亲和力——开头用疑问语气引发好奇，中间讲解清晰有条理，结尾口诀部分节奏稍慢、咬字清晰。

6. 字幕规范：字幕位置在画面底部安全区内，距底部边缘 80px；白色文字 + 半透明黑色背景条（圆角 4px，高度 40px）；字号 28px，每行不超过 20 个中文字符。口诀部分的字幕可以适当加大到 36px，居中显示。
