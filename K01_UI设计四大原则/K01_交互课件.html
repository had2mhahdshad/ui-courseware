UI 设计四大基本原则

UI 设计不是"凭感觉"的艺术，而是有章可循的科学。
以下四大原则，是判断一个设计"好不好用"的基本标尺。

🎯

一致性原则

CONSISTENCY

视觉、操作、术语三统一，降低用户的学习成本和认知负担。

基础 · 最关键
🧠

易用性原则

USABILITY

降低认知成本，让用户"凭直觉"就能操作，不需要读说明书。

目标 · 用户友好
📐

层级性原则

HIERARCHY

信息主次分明，通过视觉权重建立优先级，引导用户视线。

手段 · 信息架构
📱

规范性原则

STANDARDIZATION

遵循平台设计规范（iOS HIG / Material Design），利用用户已有的心智模型。

保障 · 平台共识
🎯

一致性原则（Consistency）— 三统一

一致性是四大原则的基础。一个不一致的设计，会让用户每到一个新页面都要"重新学习"，认知负担大大增加。

🎨
视觉统一
颜色、字体、图标风格、圆角大小、间距规范保持一致
👆
操作统一
相同功能的交互方式一致，如返回按钮始终在同一位置
📝
术语统一
同一概念在不同场景用相同表述，不混用同义词
🧠

易用性原则（Usability）— 直觉化

易用性是设计的目标。好的设计应该让用户"不用想就会用"——操作符合直觉，出错了也能轻松补救。

易用性维度说明设计方法
可识别性用户能快速理解元素功能使用通用图标 + 文字标签
可预测性操作结果符合预期遵循常见交互模式，不"反常识"
容错性出错后能轻松挽回提供撤销、确认、错误提示
📐

层级性原则（Hierarchy）— 主次分明

层级性是信息传达的手段。用户的注意力是有限的——通过大小、颜色、间距、留白的差异化，告诉用户"先看什么，后看什么"。

💡 层级四要素：大小 ↑ / 颜色对比 ↑ / 间距留白 ↑ / 位置优势
—— 越重要的元素，这四个维度的权重越高。
📱

规范性原则（Standardization）— 遵循平台

规范性是设计的保障。每个平台（iOS / Android / Web）都有自己的设计语言和用户习惯。遵循规范，就是利用用户已经建立的心智模型，降低学习成本。

平台设计规范核心理念
iOSHuman Interface Guidelines (HIG)简洁、优雅、重内容轻装饰
AndroidMaterial Design拟物化纸片、投影、动效
WebWAI-ARIA / WCAG无障碍访问、通用可用性
📌 四原则的关系：
一致性是基础，易用性是目标，层级性是手段，规范性是保障。
四者相辅相成，共同构成了好设计的底层框架。

同一个 App 里，首页的返回按钮在左边，详情页的返回按钮在右边，这样可以增加新鲜感。
✗ 答错了
这违反了一致性原则。返回按钮的位置属于"操作一致性"的范畴——用户已经形成了"返回按钮在左边"的肌肉记忆，随意改变位置会增加误触率和认知负担。设计应该追求一致，而不是"新鲜感"。

STEP 4

模拟面试

试试用四大原则回答真实的面试题，
检验一下你对 UI 设计基础的理解深度。

👨‍💼
面试官：请说说你对 UI 设计四大基本原则的理解，并举一个你做过的例子说明如何运用一致性原则。
🤔 先想想你的答案
✅ 参考答案：从以下 5 个要点展开回答
1
一致性（Consistency）：视觉/操作/术语三统一 一致性是四大原则的基础。通过统一的视觉语言、交互方式和术语表述，降低用户的学习成本和认知负担。例如，所有页面的返回按钮都放在左上角，用户不需要每次重新寻找。
2
易用性（Usability）：操作直觉化，减少思考和出错 易用性是设计的目标。好的设计应该让用户"凭感觉"就能操作，不需要读说明书。核心是可识别性、可预测性和容错性——让用户一眼看懂、操作有预期、出错能挽回。
3
层级性（Hierarchy）：通过视觉权重建立信息优先级 层级性是信息传达的手段。通过大小、颜色、间距、留白的差异化，引导用户的视线流动——让用户先看到最重要的信息，再看次要信息，避免"信息一片平"。
4
规范性（Standardization）：遵循平台规范，利用心智模型 规范性是设计的保障。每个平台有自己的设计语言和用户习惯（iOS HIG / Material Design）。遵循规范就是利用用户已有的心智模型，降低学习成本，让产品"看起来就会用"。
5
四原则相辅相成：基础 · 目标 · 手段 · 保障 一致性是基础，易用性是目标，层级性是手段，规范性是保障。四个原则不是孤立的，而是相互支撑的整体——一致的设计更易用，清晰的层级帮助规范落地，平台规范提供一致性的参考。

设计四原则口诀

四大原则记不住？试试这个口诀——
一句话一个原则，好记又好用。

🎯 ① 统一不混乱

视觉、操作、术语三统一。颜色不乱用、字体不混搭、按钮位置不变来变去。一致性是用户体验的基石——用户越熟悉，用起来越顺手。

🧠 ② 好用不费脑

操作直觉化，用户"凭感觉"就能用。图标要通用、交互要可预测、出错能撤销。好设计就是让用户不用"停下来想"。

📐 ③ 分明不迷路

信息有主次，层级要清晰。通过大小、颜色、间距、留白建立视觉权重，告诉用户"先看什么、后看什么"。页面越有层级，用户越不容易迷路。

📱 ④ 规范不犯错

遵循平台设计规范，不" reinvent the wheel"。iOS 用 HIG、Android 用 Material Design，利用用户已经建立的心智模型——站在巨人的肩膀上做设计。
