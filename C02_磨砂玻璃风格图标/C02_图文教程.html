步骤二：绘制基础形状

2
相机图标基础造型
部件工具参数
机身R RectangleW:72 H:56 圆角:16px 填充:#FFFFFF
镜头O EllipseW:28 H:28 居中 填充:#FFFFFF
闪光灯O EllipseW:8 H:8 右上角 填充:#FFFFFF
合并Ctrl+Shift+UBoolean Union 合并为单一路径
为什么要合并？把多个形状合并为一个路径后，可以统一添加玻璃效果，避免每层形状各自有效果导致混乱。

步骤三：背景模糊效果

3
Background Blur + 半透明填充
效果属性值说明
背景模糊Background Blur10 px磨砂质感核心来源
填充透明度Fill Opacity60%让模糊的背景透出来
注意：Background Blur 是模糊"形状后面的背景"，不是模糊形状本身。如果填充是纯白不透明的，模糊效果完全看不见——必须降低填充不透明度。

步骤四：高光边缘

4
Inner Shadow + 白描边
效果参数值作用
Inner ShadowX / Y / Blur / Color / Opacity0 / 1px / 2px / 白 / 60%顶部高光，模拟玻璃反光
StrokeWidth / Color / Opacity1px / 白 / 40%边缘描边，增强玻璃边界
高光边缘是点睛之笔：Inner Shadow 的 Y 值为正（1px），阴影从顶部向内投射，形成顶部亮边——就像光线照在玻璃上的反射效果。再配合半透明白色描边，玻璃的厚度感就出来了。

步骤五：投影增强立体感

5
Drop Shadow 悬浮效果
效果参数值
Drop ShadowX / Y / Blur / Color / Opacity0 / 4px / 12px / 黑 / 15%

投影让玻璃图标从背景中"浮"起来，增强立体感和悬浮感。注意投影不要太重——15% 不透明度刚刚好。
